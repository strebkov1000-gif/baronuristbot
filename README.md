# PRAVO XII - Telegram Booking Bot

Telegram-бот для бронирования юридических консультаций с интеграцией TON Blockchain.

## Возможности

- 📅 Бронирование консультаций через красивый WebApp календарь
- 💎 Автоматическая проверка TON-платежей
- 📝 Система анкет для клиентов
- 👨‍💼 Админ-панель для управления бронированиями
- 🔔 Автоматические уведомления

## Технологии

- Node.js 20+ + TypeScript
- Telegraf (Telegram Bot Framework)
- PostgreSQL + Prisma ORM
- Express (WebApp сервер)
- @ton/ton (TON Blockchain)

## Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка БД

```bash
# Создайте PostgreSQL базу данных
createdb pravo_xii_bot

# Примените миграции
npx prisma migrate dev

# Заполните начальными данными
npm run prisma:seed
```

### 3. Настройка .env

```bash
cp .env.example .env
# Отредактируйте .env файл
```

### 4. Запуск

```bash
# Для разработки
npm run dev

# Для продакшна с PM2
pm2 start ecosystem.config.js
```

## Команды бота

### Для пользователей
- `/start` - Начать работу
- `/help` - Помощь

### Для админов
- `/admin` - Админ-панель
- `/bookings` - Бронирования на сегодня
- `/week` - Бронирования на неделю
- `/stats` - Статистика
- `/confirm <id>` - Подтвердить оплату
- `/cancel <id>` - Отменить бронирование

## Сценарии использования

1. **Онлайн консультация** (40$)
2. **Письменная консультация** (90$)  
3. **Правовое заключение** (150$)
4. **Иные услуги** (договорная)

Первые 3 услуги включают:
- Выбор даты и времени в WebApp
- Предоплату 25% через TON
- Заполнение анкеты

Услуга "Иные" сразу открывает анкету для связи с менеджером.
